# Niyantri Cafe Website

A complete, production-ready coffee shop website generated from a single category prompt. This project uses Tailwind CSS via CDN and 100% Tailwind utility classes for styling. It includes four pages: Home (index.html), Menu (menu.html), About (about.html), and Contact (contact.html).

Files
- index.html: Home page with hero, quick highlights, and navigation
- menu.html: Coffee menu with items and prices
- about.html: The story and mission of Niyantri Cafe
- contact.html: Contact form for inquiries
- README.md: This documentation

How to run
- Open the four HTML files in a modern browser. No server is required; content is static.

Design system notes
- Color palette tailored for a coffee shop vibe: warm coffee tones, cream background colors, and earthy accents
- Typography: headings use Montserrat-like styling, body uses Open Sans-like styling (via Tailwind arbitrary font values in class names)
- All pages use Tailwind classes only (no external CSS files)

Fonts placeholder approach
- Headings: font-[Montserrat]
- Body: font-[OpenSans] (open-sans is represented as OpenSans in this setup to avoid spaces in class names)

- All internal links point to index.html, menu.html, about.html, and contact.html
